# Event Support BFN — Standalone Site Inspection App

No Firebase or AppSheet.

Includes Inspector/Manager role selection, event details, the 20-point safety checklist, findings and corrective actions, camera/photo attachment with previews, digital signatures, automatic document numbering, local drafts/history, manager approval/return workflow, and final report print/save-to-PDF.

Records are stored on the device in this standalone version. It does not synchronize between two phones. Cross-device synchronization requires a backend.
